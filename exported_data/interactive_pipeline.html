Step Details & Code
STEP 1 Data Shape: (153, 147)

Retail Price Ingestion & Cleaning

Loads the primary food retail price spreadsheet, registers datetimes as an index, and cleans values.

Key Actions

  • Parses raw Excel sheets using openpyxl module.
  • Standardizes date index to Month Start (MS) frequency.
  • Coerces price columns to floats and treats non-numeric data as NaNs.
  • Applies ffill(), bfill(), and time-based linear interpolation to resolve missing values.

# Loading retail food prices
df = pd.read_excel(self.filepath, sheet_name=self.sheet)
df["Month"] = pd.to_datetime(df["Month"])
df = df.sort_values("Month").reset_index(drop=True)
df.set_index("Month", inplace=True)
df = df.asfreq("MS") # Enforce monthly MonthStart frequency
df = df.ffill().bfill() # Handle missing points
